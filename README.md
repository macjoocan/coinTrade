## 1. 시스템 개요

### 1.1 핵심 목표
- **목표 수익률**: 거래당 3.0% 이상 (스윙 트레이딩)
- **리스크 관리**: 손절 1.5%, 일일 손실 3% 제한
- **거래 빈도**: 하루 최대 20회
- **보유 시간**: 최소 12시간, 이상적 24시간

### 1.2 시스템 특징
```
멀티 시그널 통합 → 신호 가중 평균 → 진입 점수 산출 → 리스크 체크 → 거래 실행
         ↓
    스윙 홀딩 모니터링 → 시간 기반 청산 판단 → 적응형 점수 조정 → 성과 분석
```

### 1.3 3단계 방어선
1. **진입 방어**: 엄격한 신호 검증 (3가지 신호 통합 + 시장 조정)
2. **보유 방어**: 스윙 홀딩 기반 실시간 손절/익절 모니터링
3. **전략 방어**: 히스토리 기반 자동 점수 조정

### 1.4 주요 모듈 구성

| 모듈 | 파일 | 역할 |
|------|------|------|
| 메인 봇 | `main_trading_bot.py` | 거래 실행 및 전체 조율 |
| 전략 | `improved_strategy.py` | 기술적 분석 및 신호 생성 |
| 리스크 관리 | `risk_manager.py` | 포지션 크기 및 손익 관리 |
| MTF 분석 | `mtf_analyzer.py` | 멀티 타임프레임 분석 |
| ML 예측 | `ml_signal_generator.py` | 머신러닝 기반 예측 |
| 스윙 홀딩 | `swing_holding_enhancer.py` | 보유 시간 기반 청산 판단 |
| 적응형 점수 | `adaptive_score_manager.py` | 히스토리 기반 점수 자동 조정 |
| 설정 | `config.py` | 전체 설정 관리 (settings.json 로드) |

## 4. 신호 생성 로직

### 4.1 기술적 분석 신호 (25% 가중치)

#### 점수 구성

```
1. 추세 분석 (최대 2.5점)
   ├─ 강한 상승: EMA 정배열 + Price > SMA20 → +2.5점
   ├─ 상승 추세: SMA20 > SMA50 → +1.5점
   └─ 추세 정배열 초입 → +1.5점

2. RSI 분석 (최대 3.0점)
   ├─ RSI 30~40: 과매도 반등 → +3.0점 ⭐
   ├─ RSI 40~50: 눌림목/박스권 하단 → +3.0점
   ├─ RSI 50~60: 건강한 수준 → +2.0점
   └─ RSI ≥ 70: 과매수 위험 → +0.0점

3. MACD 분석 (최대 2.0점)
   ├─ MACD > Signal AND MACD > 0: 강세 → +2.0점
   └─ MACD > Signal: 양전환 → +1.5점
```

### 4.2 멀티 타임프레임 분석 (45% 가중치)

```
┌─────────────────────────────────────────┐
│ 1시간봉 (가중치 30%)                      │
│ • 단기 추세 및 진입 타이밍                 │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 4시간봉 (가중치 40%) ⭐ 가장 중요          │
│ • 중기 추세 방향 결정                      │
│ • 스윙 트레이딩의 핵심 타임프레임           │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 일봉 (가중치 30%)                         │
│ • 장기 추세 확인                          │
└─────────────────────────────────────────┘

합의도 (Consensus):
- 최소 70% 합의 필요
- 합의도 ≥ 85%: 강한 신호
- 합의도 < 70%: 약한 신호
```

### 4.3 머신러닝 예측 (30% 가중치)

```
모델: RandomForest (100 trees, max_depth=10)

특성 (30개):
├─ 가격 특성: 1h, 4h, 24h 수익률
├─ 이동평균: SMA10/20/50, 가격/SMA 비율
├─ 기술적 지표: RSI, MACD, 볼린저 밴드
├─ 변동성: 표준편차, ATR
├─ 거래량: 평균, 비율, 변화율
└─ 시간 특성: 시간, 요일

레이블: 6시간 후 수익률 > 1.5% → 긍정(1)

예측 평가:
- 매수 확률 ≥ 65%: 신호 활성화
- 매수 확률 < 65%: 신호 약함
```

```

    ↓ PASS
Gate 3: 최대 포지션 수 (1개)
```

## 8. 스윙 홀딩 시스템

### 8.1 개요

스윙 트레이딩에 최적화된 보유 시간 기반 청산 시스템

```
설정:
├─ 최소 보유 시간: 12시간
├─ 이상적 보유 시간: 24시간
├─ 조기 익절 기준: +2.5%
├─ 좋은 수익 기준: +3.0%
└─ 탁월한 수익 기준: +5.0%
```

### 8.2 청산 판단 로직

```
┌───────────────────────────────────────┐
│ 보유 시간 < 12시간                      │
├───────────────────────────────────────┤
│ • 손절만 허용 (-1.5%)                   │
│ • 익절 금지 (조급한 익절 방지)           │
│ • 수익 +2.5% 이상이어도 보유 유지         │
└───────────────────────────────────────┘
           ↓
┌───────────────────────────────────────┐
│ 보유 시간 12~24시간                     │
├───────────────────────────────────────┤
│ • 수익 +2.5% 이상: 조기 익절 허용        │
│ • 수익 +3.0% 이상: 적극 익절 권장        │
│ • 그 외: 계속 보유                       │
└───────────────────────────────────────┘
           ↓
┌───────────────────────────────────────┐
│ 보유 시간 > 24시간                      │
├───────────────────────────────────────┤
│ • 수익이면 청산                         │
│ • 손실이면 손절 또는 추가 대기           │
└───────────────────────────────────────┘
```

## 9. 적응형 점수 자동 조정

### 9.1 개요

거래 히스토리를 분석하여 진입 점수 기준을 자동으로 조정하는 시스템

```
설정:
├─ 분석 주기: 4시간
├─ 분석 기간: 최근 7일
├─ 최소 거래 수: 10건
├─ 목표 승률: 50%
├─ 최대 조정폭: ±0.5점
└─ 점수 범위: 4.0 ~ 8.0점
```

### 9.2 조정 로직

```
┌───────────────────────────────────────┐
│ 1. 승률 기반 조정                       │
├───────────────────────────────────────┤
│ • 승률 < 40%: 점수 +0.2 (더 엄격)       │
│ • 승률 < 50%: 점수 +0.1                │
│ • 승률 > 65%: 점수 -0.1 (더 많은 기회)  │
└───────────────────────────────────────┘
           ↓
┌───────────────────────────────────────┐
│ 2. 연속 손실 대응                       │
├───────────────────────────────────────┤
│ • 연속 3회 손실: 점수 +0.1              │
│ • 연속 3회 수익: 점수 -0.05             │
└───────────────────────────────────────┘
           ↓
┌───────────────────────────────────────┐
│ 3. 평균 수익률 기반                     │
├───────────────────────────────────────┤
│ • 평균 < -1%: 점수 +0.1                │
│ • 평균 > +2%: 점수 -0.05               │
└───────────────────────────────────────┘
           ↓
┌───────────────────────────────────────┐
│ 4. 최종 조정 적용                       │
├───────────────────────────────────────┤
│ • 최대 ±0.5점 제한                      │
│ • 4.0 ~ 8.0 범위 제한                  │
│ • 실시간 config 업데이트                │
└───────────────────────────────────────┘
```

### 9.3 조정 이력 저장

```json
// score_adjustment_history.json

  "last_updated": "2026-01-18T20:30:00",
  "current_score": 5.6,

      "new_score": 5.6,
```

## 📝 부록: 용어 정리

### 기술 용어
- **RSI (Relative Strength Index)**: 상대강도지수, 과매수/과매도 판단
- **MACD**: 이동평균 수렴/확산, 추세 전환 포착
- **MTF (Multi Time Frame)**: 멀티 타임프레임, 여러 시간대 종합 분석
- **EMA/SMA**: 지수/단순 이동평균

### 전략 용어
- **스윙 트레이딩**: 12~48시간 보유하는 중기 거래 전략
- **물타기 (Averaging Down)**: 하락 시 추가 매수로 평단 낮추기
- **적응형 점수**: 히스토리 기반 자동 조정되는 진입 기준

### 파일 구조
- `trade_history.json`: 전체 거래 기록
- `active_positions.json`: 현재 보유 포지션
- `score_adjustment_history.json`: 점수 조정 이력
- `score_performance.json`: 점수별 성과 통계
